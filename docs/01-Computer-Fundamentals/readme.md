# Computer Fundamentals

## Overview

Computer Fundamentals are the building blocks of Computer Science and Cybersecurity. Every operating system, network, web application, and security tool ultimately runs on computer hardware. A strong understanding of these concepts makes learning Linux, Networking, Cloud Computing, Web Security, Malware Analysis, and Digital Forensics much easier.

---

## Learning Objectives

After completing this section, you should be able to:

- Understand how a computer works
- Differentiate between hardware, software, and firmware
- Explain CPU architecture and memory hierarchy
- Understand RAM, ROM, Cache, SSD, and HDD
- Explain the computer boot process
- Understand files, directories, paths, disks, partitions, and filesystems
- Explain operating system basics before moving to Linux
- Build a strong foundation for cybersecurity
