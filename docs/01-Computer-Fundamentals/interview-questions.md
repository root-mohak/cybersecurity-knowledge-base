# Computer Fundamentals

## Overview

This section documents the core concepts of Computer Fundamentals required for Cybersecurity, Operating Systems, Networking, Cloud Computing, and Web Security.

The purpose of this section is **not** to learn computers from scratch, but to revise, strengthen understanding, and document concepts that are used throughout a cybersecurity career.

These notes focus on concepts that every cybersecurity professional should understand before moving into Linux, Networking, Web Security, Cloud, Digital Forensics, and Malware Analysis.
