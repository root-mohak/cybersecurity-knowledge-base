# 🌐 Web Fundamentals

Welcome to the **Web Fundamentals** section of my **Cybersecurity Knowledge Base**.

This section documents my journey of learning how the web works—from the basics of the Internet to building websites with HTML, CSS, and JavaScript. The primary goal is to build a strong foundation for **Web Security**, **Application Security**, and **Penetration Testing**.

---

# 🎯 Learning Goals

By completing this section, I aim to:

- Understand how the Internet works
- Learn the complete lifecycle of a website
- Master HTML, CSS, and JavaScript fundamentals
- Understand how browsers render web pages
- Learn HTTP/HTTPS communication
- Understand client-server architecture
- Build small web projects
- Prepare for Web Security concepts such as XSS, CSRF, SQL Injection, Authentication, and OWASP Top 10

# 🔐 Why Web Fundamentals Matter for Cybersecurity

Understanding how websites are built is essential before learning how they can be attacked and secured.

These fundamentals form the foundation for:

- Web Application Security
- Penetration Testing
- OWASP Top 10
- Cross-Site Scripting (XSS)
- SQL Injection
- CSRF
- Authentication
- Session Management
- Browser Security
- Secure Development
